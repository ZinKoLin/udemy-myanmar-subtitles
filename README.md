# Udemy မြန်မာစာတန်း

ကိုယ်တိုင်သုံးရန် Chrome / Edge Manifest V3 extension ဖြစ်ပါသည်။ Build သို့မဟုတ် npm package တင်ရန် မလိုပါ။

မှတ်ချက် — အောက်တွင် ဖော်ပြထားသော `evidence/` စမ်းသပ်မှတ်တမ်းများကို ကိုယ်ပိုင်စက်တွင်သာ သိမ်းထားပြီး Git repository တွင် မထည့်ထားပါ။

## Version 0.8.0 — Cache အလိုအလျောက်ရှင်းခြင်းနှင့် နောက်ခံအလုပ်လျှော့ခြင်း

- Chrome ဖွင့်ထားချိန် နာရီတိုင်း cache maintenance စစ်ပါသည်။ နောက်ဆုံးမသုံးဘဲ **30 ရက်** ကျော်သည့် cache၊ စုစုပေါင်း **4 MiB** သို့မဟုတ် **500 entries** ကျော်သည့် cache များကို နောက်ဆုံးသုံးထားသည့်အချိန် အဟောင်းမှစ၍ ရှင်းပါသည်။
- ဖွင့်ထားသော Udemy tab တစ်ခုချင်းစီ၏ လက်ရှိသင်ခန်းစာကို pin လုပ်ပြီး ထိုသင်ခန်းစာတွင် သုံးခဲ့သည့် browser/API စာတန်း cache ကို မရှင်းပါ။ ထို့ကြောင့် ကာကွယ်ထားသော cache များကြောင့် သတ်မှတ်ပမာဏ ကျော်နိုင်ပါသည်။ Tab ပိတ်ခြင်း သို့မဟုတ် lecture ပြောင်းခြင်းနောက် maintenance စစ်ချိန်တွင် pin ကို ဖြုတ်ပါသည်။
- Upgrade ပြီးစာမျက်နှာအဟောင်း ဖွင့်ထားဆဲဖြစ်၍ လက်ရှိစာတန်း cache ကို မသတ်မှတ်နိုင်သေးလျှင် cleanup ကို ဆိုင်းထားပါသည်။ လက်ရှိသင်ခန်းစာကို အဆင်ပြေချိန် Reload လုပ်လျှင် version အသစ်နှင့် cache pin ပြန်ချိတ်ပါသည်။ Account၊ API keys၊ n8n token၊ model၊ subtitle settings များသည် cleanup ဖျက်နိုင်သော key စာရင်းတွင် မပါပါ။
- Popup မှ **Clear old translation cache** နှိပ်လျှင်လည်း လက်ရှိသင်ခန်းစာများကို ချန်ပြီး အသုံးမပြုသော cache ကိုသာ ရှင်းပါသည်။ Settings ကို မဖျက်ပါ။
- Gemini adapter သည် နောက်ဆုံးအဖြေကိုသာ ဖတ်ပြီး chat အဟောင်းတစ်ခုလုံး၏ စာသားကို ထပ်ဖတ်ခြင်း မလုပ်ပါ။ အလုပ်ပြီး/မအောင်မြင်/ရပ်ထားချိန် polling timer နှင့် အဖြေစာသား buffer ကို ရှင်းပြီး နောက်အလုပ်လာမှ ပြန်စပါသည်။ SRT upload claim ပြီးလျှင် worker ထဲက မူရင်း SRT string ကို ရှင်းပါသည်။
- Udemy video ရပ်ထားစဉ် မပြောင်းသောစာတန်းကို ထပ်မရေးပါ။ Video element ရှာခြင်းကို တစ်စက္ကန့်တစ်ကြိမ်အထိ လျှော့ထားပြီး playback၊ seek၊ scroll၊ resize နှင့် fullscreen ပြောင်းချိန် စာတန်းနေရာပြန်ညှိပါသည်။ လက်ရှိ cue နှင့် ဘာသာပြန်စာသားများကို မဖျက်ပါ။ Chrome/Gemini website ၏ RAM ပမာဏကို hard limit မထားပါ။

## Version 0.7.1 — Flash-Lite အချိန်အတိအကျနှင့် ဘာသာပြန်နေကြောင်းပြခြင်း

Gemini အဖြေထဲက timestamp များကို playback တွင် မသုံးပါ။ Cue နံပါတ်၊ အစဉ်၊ စာကြောင်းအရေအတွက်နှင့် စာသားအပြည့်ကို စစ်ပြီး မူရင်း SRT ၏ start/end အချိန်နှင့် ဘာသာပြန်စာသားကို တွဲပေးပါသည်။ Model က အချိန်လုံးဝပြောင်းရေးသော်လည်း မူရင်း cue အချိန်ကိုသာ သုံးပါသည်။ Cue ပျောက်ခြင်း၊ ထပ်ခြင်း၊ နံပါတ်/အစဉ်ပြောင်းခြင်းနှင့် partial အဖြေများကို ဆက်ပယ်ချပါသည်။ Server မှ ထွက်လာသော SRT ကိုလည်း မူရင်းအချိန်ဖြင့် ပြန်ထုတ်ပါသည်။

Panel ခေါက်ထားလည်း **⏳ ဘာသာပြန်နေပါသည်။ စာတန်းမရသေးပါ။ အသင့်ဖြစ်မှ Play နှိပ်ကြည့်ပါ။** ဟူသော အဝါရောင် notice ပြပါသည်။ Full SRT အဖြေကို စောင့်နေချိန် video ကို ခဏရပ်ထားပြီး Play နှိပ်လျှင်လည်း အလိုအလျောက် ပြန်ရပ်ပါသည်။ အဖြေအပြည့်ရလျှင် အစိမ်းရောင် ready notice ပြပြီး အသုံးပြုသူက Play နှိပ်ကြည့်နိုင်ပါသည်။ မအောင်မြင်လျှင် စာတန်းမရသေးကြောင်း အနီရောင် notice ပြပါသည်။

လက်တွေ့စမ်းသပ်မှု (2026-11-15): `Downloadable Resources and Tips for Taking the Course` တွင် Flash-Lite ဖြင့် cache မသုံးဘဲ SRT ဖိုင်တစ်ခုလုံး ပို့ကာ **59/59** ပြန်ရပြီး Udemy တွင် စာတန်းပြနိုင်ခဲ့ပါသည်။ Playback 25.14 စက္ကန့်၌ English “And how do you use all the tools … and resources we built for you” နှင့် သက်ဆိုင်သော မြန်မာစာတန်း တူညီနေကြောင်း စစ်ထားပါသည်။ နောက်သင်ခန်းစာတွင် အဝါရောင် loading notice ပေါ်နေစဉ် Play နှိပ်သော်လည်း video ပြန်ရပ်ကြောင်း စစ်ထားပါသည်။ Flash-Lite က 33 ကြောင်းအစား 32 ကြောင်းပြန်ပေးသည့်အဖြေကို နှစ်ကြိမ်စလုံး ပယ်ချပြီး အနီရောင် မပြီးသေးကြောင်း notice ပြပါသည်။ Model စာကြောင်းပေါင်း/ပျောက်သည့်ပြဿနာကို timestamp ပြင်ခြင်းဖြင့် ဖြေရှင်းမရသဖြင့် အဖြေမှားကို မပြသပါ။ Tests 59 ခုနှင့် syntax checks အောင်ပါသည်။ အထောက်အထားပုံများကို ကိုယ်ပိုင် `evidence/` ဖိုင်တွဲ၌ သိမ်းထားပါသည်။

## Version 0.7.0 — Model ရွေးခြင်းနှင့် Hydrogen Medium default

Gemini browser နှင့် n8n server နည်းလမ်းများအတွက် **Hydrogen Medium** ကို မူလ model အဖြစ် သုံးပါသည်။ Udemy subtitle panel သို့မဟုတ် extension popup မှ **Gemini browser model** တွင် Hydrogen Medium၊ Argon Medium၊ Flash-Lite သို့မဟုတ် Gemini မှာ ကိုယ်တိုင်ရွေးထားသည့် model ကို ရွေးနိုင်ပါသည်။ ရွေးလိုက်သည်နှင့် သိမ်းပြီး လက်ရှိအလုပ်ကို ရပ်ပါသည်။ **Translate** ပြန်နှိပ်မှ model အသစ်ဖြင့် အစအဆုံး ပြန်ပို့ပါသည်။ မူလ API model setting နှင့် Pro account ကို မပြောင်းပါ။

ကိုယ်တိုင်ရွေးသည့်နည်းကို သုံးလျှင် dedicated Gemini chat ထဲတွင် model ကို အရင်ရွေးပါ။ ဤနည်းမှာ model ကို အတိအကျ မသိနိုင်သဖြင့် ယခင်ဘာသာပြန် cache ကို ပြန်မသုံးပါ။ အခြားရွေးချယ်မှုများအတွက် cache ကို model အလိုက် ခွဲသိမ်းပါသည်။ Gemini က model ကို limit ကြောင့် ပိတ်ထားလျှင် ထို limit သည် ဆက်သက်ရောက်ပါသည်။ အလိုအလျောက် model ပြောင်းမသုံးပါ။

n8n အသုံးပြုသူများသည် server package ကိုလည်း update လုပ်ပါ။ Webhook workflow က model ရွေးချယ်မှုကို server သို့ ဆက်ပို့ပါသည်။

လက်တွေ့စမ်းသပ်မှု: v0.7.0 Reload ပြီး Udemy မှ Flash-Lite ပြောင်းရွေး၊ SRT အစအဆုံးပို့၊ အဖြေပြန်ဖတ်နိုင်ခဲ့ပါသည်။ စမ်းသပ်အဖြေတွင် timestamp ပြောင်းထားသဖြင့် strict validation က ပယ်ချပြီး စာတန်းမတင်ခဲ့ပါ။ Hydrogen Medium ကို မူလရွေးချယ်မှုအဖြစ် ပြန်သိမ်းထားပါသည်။ Hydrogen ဖြင့် live ဘာသာပြန်အောင်မြင်မှုကို လက်ရှိ account limit အတွင်း မအတည်ပြုနိုင်သေးပါ။ Automated tests 55 ခုနှင့် syntax checks အောင်ပါသည်။

## Version 0.6.0 — နည်းလမ်းရွေးချယ်မှု၊ chat တစ်ခုတည်းနှင့် အသင့်ဖြစ်ကြောင်းပြခြင်း

Extension နှင့် Udemy စာမျက်နှာကို Reload တစ်ကြိမ်လုပ်ပါ။ Popup သို့မဟုတ် Udemy subtitle panel မှ နည်းလမ်းသုံးခု ရွေးနိုင်ပါသည်။

- **Gemini API — original method**: မူလနည်းလမ်းအတိုင်း API key နှင့် model ရွေးပြီး 24 ကြောင်းစီ ဘာသာပြန်ပါသည်။ ယခင် keys၊ model၊ fallback နှင့် cache များကို မဖျက်ပါ။
- **Gemini browser — full SRT**: သတ်မှတ်ထားသော Pro အကောင့်၏ **Argon Medium** ဖြင့် SRT ဖိုင်တစ်ခုလုံး ပို့ပါသည်။ နောက်သင်ခန်းစာတွင် Gemini chat အသစ်တစ်ခု ထပ်မဖန်တီးဘဲ သိမ်းထားသော dedicated chat ကို ဆက်သုံးပါသည်။ Tab ပိတ်ထားလျှင်လည်း သိမ်းထားသော conversation URL ကို ပြန်ဖွင့်ပါသည်။ အသုံးပြုသူက အဲဒီ tab ကို အခြား chat သို့ ပြောင်းထားလျှင် ထို chat ထဲတွင် မပို့ဘဲ dedicated conversation ကို ပြန်ဖွင့်ပါသည်။ Extension update နောက် adapter ဟောင်းဖြစ်နေပါက chat တူကို Reload လုပ်၍ ပြန်ချိတ်ပါသည်။
- **n8n server — full SRT**: n8n webhook သို့ SRT ပို့ပြီး server browser မှ ဘာသာပြန်ပါသည်။ ဒီစက်မှာ Gemini tab မဖွင့်ပါ။ Server မတပ်ရသေးလျှင် မသုံးနိုင်သေးပါ။ [Server တပ်ဆင်ရန်](server/README.md) ကိုဖတ်ပါ။ Import လုပ်နိုင်သော workflow သည် `server/n8n-workflow.json` ဖြစ်ပါသည်။

ဘာသာပြန်အကုန်ပြီးလျှင် Udemy panel ခေါက်ထားချိန်တွင်ပါ **✓ စာတန်းထိုး အသင့်ဖြစ်ပြီ — N / N** ဆိုသော notice နှင့် **✓ Subtitles ready** ခလုတ် ပြပါသည်။ Lecture၊ source file သို့မဟုတ် နည်းလမ်းပြောင်းလျှင် အဟောင်း၏ ready notice ကို ဖျောက်ပါသည်။

Chat တစ်ခုတည်းကို ဆက်သုံးသော်လည်း Gemini ၏ context/output/quota ကန့်သတ်ချက်များ သက်ရောက်ပါသည်။ Website UI ပြောင်းလဲလျှင် adapter ပြင်ရန် လိုနိုင်ပါသည်။

## Gemini key အများအပြားနှင့် model ရွေးချယ်မှု

- Extension popup မှ **Add API key** နှိပ်ပြီး ကိုယ်ပိုင် key 8 ခုအထိ ထည့်နိုင်ပါသည်။ Key များကို password အဖြစ် ဖျောက်ပြထားပြီး **Save settings** နှိပ်မှ သိမ်းပါသည်။ ထပ်တူ key များကို တစ်ခုအဖြစ်သာ သိမ်းပါသည်။ မူလက သိမ်းထားသည့် key တစ်ခုတည်းကို ဆက်သုံးနိုင်ပြီး ပထမ Save လုပ်ချိန်မှာ key စာရင်းပုံစံသို့ ပြောင်းသိမ်းပါသည်။
- **Switch keys automatically on quota or key errors** ကို မူလအတိုင်း ဖွင့်ထားပါသည်။ HTTP 429 ဖြစ်လျှင် နောက် key ကို ထို request အတွက် ဆက်သုံးပါသည်။ အောင်မြင်သော key ကို နောက်တစ်ခါ ဦးစားပေးသုံးပါသည်။ 401 / 403 နှင့် API key မမှန်သည့် 400 error တို့တွင်လည်း နောက် key ကို စမ်းပါသည်။
- ကန့်သတ်ထားသော key ကို Gemini ၏ Retry-After / retryDelay အတိုင်း ခဏနားထားပါသည်။ API က အချိန်မပေးလျှင် 60 စက္ကန့်၊ key အသုံးပြုခွင့် error အတွက် 10 မိနစ် နားပါသည်။ အခြေအနေကို စက်ထဲမှာ သိမ်းထားသဖြင့် worker ပြန်စသော်လည်း ချက်ချင်းပြန်မခေါ်ပါ။ Request တစ်ခုတွင် key တစ်ခုကို တစ်ကြိမ်သာ စမ်းပြီး key အားလုံးမရလျှင် error ပြကာ ရပ်ပါသည်။ Network error၊ server error နှင့် model မရှိသည့် 404 တို့ကို key တိုင်းဖြင့် ထပ်မစမ်းပါ။
- Key ပြောင်းသုံးမှုကို ပိတ်ထားပါက လက်ရှိ key တစ်ခုတည်းကိုသာ သုံးပါသည်။ **Last request** မှာ နောက်ဆုံးသုံးထားသည့် key နံပါတ်ကို ကြည့်နိုင်ပါသည်။
- **Gemini model** စာရင်းမှ ရွေးလိုက်သည်နှင့် အလိုအလျောက် သိမ်းပါသည်။ Model အတွက် Save settings ထပ်နှိပ်ရန် မလိုပါ။ Key ထည့်/ဖယ်ခြင်းအတွက်တော့ **Save settings** နှိပ်ပါ။ **Refresh available models** က သိမ်းထားသည့် key ဖြင့် Google ၏ model စာရင်းကို ရယူပေးပြီး လက်ရှိရွေးချယ်မှုကို မပြောင်းပါ။ ကိုယ်တိုင် ID ထည့်လိုလျှင် **Custom model…** ရွေးပြီး ID ထည့်ကာ အကွက်အပြင်နှိပ်ပါ သို့မဟုတ် Save settings နှိပ်ပါ။ ရွေးထားသည့် model သည် subtitle ဘာသာပြန်ရန် text / JSON output ကို ထောက်ပံ့ရပါမည်။ API စာရင်းထဲမှာ ပါရုံဖြင့် account အသုံးပြုခွင့်၊ quota နှင့် JSON output ထောက်ပံ့မှုကို အာမခံမပေးပါ။
- Model ပြောင်းလျှင် ဖွင့်ထားသည့် Udemy tab ထံ အကြောင်းကြားပြီး စာတန်းဟောင်းကို ရှင်းပါသည်။ အလိုအလျောက်ဘာသာပြန်မှု ဖွင့်ထားပါက model အသစ်ဖြင့် ပြန်ပြင်ဆင်ပါသည်။ ပိတ်ထားပါက **Translate** နှိပ်ပါ။ Cache သည် အမှန်တကယ်သုံးသည့် model အလိုက် ခွဲသိမ်းပါသည်။
- **Switch models on quota or timeout** ကို ဖွင့်ထားလျှင် မူလ model အတွက် ခွင့်ပြုထားသည့် key များ quota ပြည့်မှ **Fallback model 1**၊ ပြီးလျှင် **Fallback model 2** ကို အစဉ်လိုက် ဆက်စမ်းပါသည်။ မလိုသော fallback ကို **None** ရွေးနိုင်ပါသည်။ မူလရွေးချယ်မှုသည် သိမ်းထားသည့် preferred model အဖြစ် ဆက်ရှိပါသည်။ Fallback သုံးပြီးနောက် Flash သို့မဟုတ် အခြား model ကို မူလရွေးချယ်မှုအဖြစ် ပြန်မသိမ်းပါ။
- မူလ fallback များသည် `gemini-3.1-flash-lite` နှင့် `gemini-flash-lite-latest` ဖြစ်ပါသည်။ Model အလိုက် quota၊ အသုံးပြုခွင့်နှင့် အသုံးပြုခ ကွဲနိုင်ပါသည်။ Request တစ်ခုအတွက် model 3 ခုအထိသာ စမ်းပြီး အားလုံးမရလျှင် ရပ်ပါသည်။ Network / authentication error ကို model တိုင်းဖြင့် ထပ်မစမ်းပါ။ ကိုယ်ရွေးထားသော မူလ model မရှိသည့် 404 ကို ထင်ရှားစွာ ပြပါသည်။ Quota ပြီးနောက် ရွေးထားသည့် fallback က 404 ဖြစ်လျှင် နောက် fallback ကို ဆက်စမ်းပါသည်။
- Subtitle panel ၏ **Model:** နေရာတွင် အမှန်တကယ်သုံးသည့် model နှင့် **(fallback)** အမှတ်အသားကို ပြပါသည်။ Popup ၏ **Last API request** သည် နောက်ဆုံး network request ၏ model ကို ဆိုလိုပြီး မူလရွေးချယ်မှုနှင့် ကွဲနိုင်ပါသည်။ Cache မှသာ ပြန်သုံးချိန်တွင် API request အသစ် မရှိနိုင်ပါ။
- **Google project တူသည့် key များမှာ quota မျှဝေသုံးပါသည်။** Key လဲခြင်းသည် project quota ကို မတိုးပေးပါ။ [Google rate-limit လမ်းညွှန်](https://ai.google.dev/gemini-api/docs/rate-limits) နှင့် [model စာရင်း API](https://ai.google.dev/api/models) ကို ကြည့်နိုင်ပါသည်။

Version 0.3.0 တွင် အတုတုံ့ပြန်မှုဖြင့် key rotation၊ key အားလုံး limit ဖြစ်ခြင်း၊ cooldown သိမ်းဆည်းမှု၊ rotation ပိတ်ခြင်းနှင့် model စာရင်းခွင့်ပြုချက်ကို စစ်ထားပါသည်။ Chrome တွင် key အဟောင်းကို ဆက်ဖတ်နိုင်ခြင်း၊ key အလွတ်နေရာ ထည့်/ဖယ်ခြင်း၊ model စာရင်းကို API မှ ရယူနိုင်ခြင်းနှင့် settings သိမ်းခြင်းကို လက်တွေ့စမ်းထားပါသည်။ Key အစစ်များကို quota ကုန်အောင် တမင်မခေါ်စမ်းထားပါ။ အထောက်အထား — `evidence/udemy-key-rotation-models.png`။

Version 0.4.0 တွင် automated test 22 ခု အောင်ထားပါသည်။ 2026-11-15 Chrome စမ်းသပ်မှုတွင် model ကို Save မနှိပ်ဘဲ ပြောင်း၊ popup ပိတ်ပြီး ပြန်ဖွင့်ရာ၌ ရွေးထားသော model ကျန်နေခြင်းကို အတည်ပြုထားပါသည်။ စမ်းသပ်ပြီးနောက် သုံးစွဲသူ၏ မူလ `gemini-4-argon` ကို ပြန်ထားပါသည်။ Graphic Design သင်ခန်းစာတွင် မူလ model quota ဖြစ်ပြီး `gemini-3.1-flash-lite (fallback)` ကို သုံး၍ စာတန်း 153 ကြောင်း အသင့်ဖြစ်ခဲ့ပါသည် (132 ကြောင်း cache မှ)။ အထောက်အထား — `evidence/udemy-model-fallback.png`။

စာမျက်နှာဖွင့်ချိန်တွင် အပြင်အဆင် panel ကို ခေါက်ထားပြီး **⚙ Subtitles** ခလုတ်အသေးလေးသာ ပေါ်ပါသည်။ ထိုခလုတ်ကို နှိပ်လျှင် ဖွင့်နိုင်ပြီး **Collapse**၊ ခလုတ်ကို ထပ်နှိပ်ခြင်း သို့မဟုတ် panel ထဲတွင် Escape နှိပ်ခြင်းဖြင့် ပြန်ခေါက်နိုင်ပါသည်။ ခေါက်ထားချိန်တွင်လည်း စာတန်းနှင့် အလိုအလျောက်ဘာသာပြန်မှု ဆက်အလုပ်လုပ်ပါသည်။ Extension popup မှ **Open subtitle settings** နှိပ်၍လည်း ပြန်ဖွင့်နိုင်ပါသည်။ ခလုတ်၊ အညွှန်း၊ အခြေအနေပြစာသားနှင့် ဖိုင်ရွေးချယ်မှုတို့ကို English လို ဖော်ပြထားပါသည်။ သင်ခန်းစာ ဘာသာပြန်စာတန်းကို မြန်မာလို ဆက်ပြပါသည်။

## အသုံးပြုပုံ

- Video ပေါ်မှာ မြန်မာစာတန်းသာ ပြပါသည်။ မူလ English CC ကို မြင်ကွင်းမှသာ ဖျောက်ပြီး player အတွင်းမှ စာသားကို အချိန်ကိုက်ရန် ဆက်သုံးပါသည်။
- Panel မှ **စာလုံးအရွယ်အစား** (16–48 px) နှင့် **စာလုံးအရောင်** ရွေးနိုင်ပါသည်။ ရွေးထားတာကို ဒီစက်ထဲမှာ သိမ်းပြီး နောက်တစ်ခါဖွင့်ချိန်နှင့် နောက်သင်ခန်းစာတွင် ပြန်သုံးပါသည်။
- **စာတန်းနေရာ** slider ကို ဘယ်ဘက်ရွှေ့လျှင် အောက်၊ ညာဘက်ရွှေ့လျှင် အပေါ် ရောက်ပါသည်။ ရွှေ့နေစဉ် ချက်ချင်းကြည့်နိုင်ပြီး လွှတ်လိုက်ချိန်တွင် ရွေးထားသောနေရာကို သိမ်းပါသည်။ Video အပြင်ဘက် မကျော်အောင် ထိန်းထားပြီး နောက်သင်ခန်းစာနှင့် Reload ပြီးနောက်လည်း ထိုနေရာကို ပြန်သုံးပါသည်။
- **အလိုအလျောက် ဘာသာပြန်မည်** ကို မူလအတိုင်း ဖွင့်ထားပါသည်။ သင်ခန်းစာဖွင့်ချိန်နှင့် သင်ခန်းစာပြောင်းချိန်တွင် player တည်ငြိမ်ရန် ခဏစောင့်ပြီး စာတန်းရှာ၊ ဘာသာပြန်ပါသည်။ ရှာမရလျှင် အများဆုံး 3 ကြိမ်စမ်းပြီး ရပ်ပါသည်။ API error ဖြစ်လျှင် ထပ်ခါထပ်ခါ အလိုအလျောက်မခေါ်ပါ။ ပြန်စမ်းရန် **ဘာသာပြန်မည်** နှိပ်ပါ။
- လက်ရှိကြည့်သည့်အပိုင်းကို အရင်ဘာသာပြန်ပြီး ကျန်သင်ခန်းစာကို 24 ကြောင်းစီ ဆက်လုပ်ပါသည်။ သင်ခန်းစာတစ်ခုလုံးအတွက် API အသုံးပြုခ ကျသင့်နိုင်ပါသည်။ မလိုအပ်လျှင် အလိုအလျောက် ဘာသာပြန်မည်ကို ပိတ်ထားနိုင်ပါသည်။
- ဘာသာပြန်ရလဒ်ကို `chrome.storage.local` မှာ သိမ်းပါသည်။ ပြန်ကြည့်ချိန်တွင် မူလစာသား၊ အပိုင်းဖွဲ့ပုံနှင့် model တူသည့် cache ကို အလိုအလျောက် ပြန်သုံးပြီး API ထပ်မခေါ်ပါ။
- အင်တာနက်မရှိသော်လည်း player မှ စာတန်းရနိုင်လျှင် သို့မဟုတ် ဖိုင်ထည့်နိုင်လျှင် သိမ်းထားပြီးသား အပိုင်းများကို သုံးနိုင်ပါသည်။ Video offline ရမည်ဟု မဆိုလိုပါ။
- **ရပ်မည်** က ဒီသင်ခန်းစာအတွက် နောက်ထပ်အပိုင်းပို့ခြင်းကို ရပ်ပါသည်။ ပို့ထားပြီးသား API request သည် ဆက်ပြီး သိမ်းနိုင်ပါသည်။ အလိုအလျောက်ဖွင့်ထားလျှင် နောက်သင်ခန်းစာတွင် ပြန်စပါသည်။
- သင်ခန်းစာပြောင်းလျှင် စာတန်းဟောင်းရှင်းပြီး အသစ်အတွက် အလိုအလျောက် ပြန်စပါသည်။ အဟောင်းမှ နောက်ကျရောက်လာသော အဖြေကို အသစ်ပေါ်မှာ မပြပါ။ Overview / Notes tab ပြောင်းခြင်းကြောင့် အစမှပြန်မစပါ။
- စာတန်းမရလျှင် သင်ခန်းစာနှင့်ကိုက်ညီသော English `.vtt` / `.srt` ဖိုင် (5 MB အောက်) ကို panel မှ ထည့်နိုင်ပါသည်။ Plain transcript မှာ အချိန်မှတ်မပါလျှင် အသုံးမပြုနိုင်ပါ။
- Cache ရှင်းရန် popup မှ **ဘာသာပြန်မှတ်ဉာဏ် ရှင်းမည်** နှိပ်ပါ။ API key ကို မဖျက်ပါ။ Key ဖျက်ရန် key field ကိုရှင်းပြီး Settings သိမ်းပါ။ Extension ဖြုတ်ပါက သိမ်းထားသည့်ဒေတာ ပျက်ပါမည်။

## ကန့်သတ်ချက်နှင့် ဒေတာ

Browser `TextTrack`၊ `<track>` နှင့် Udemy Transcript sidebar တို့မှ စာတန်းဖတ်နိုင်ပါသည်။ လက်ရှိ Udemy Shaka player မှာ native track မရှိသဖြင့် Transcript စာကြောင်းများကို တစ်ခါဖတ်ယူပြီး memory ထဲမှာ သိမ်းပါသည်။ Sidebar ပိတ်ထားချိန်မှာ video ပေါ်က လက်ရှိ English CC စာသားနှင့် တိုက်စစ်ပြီး မြန်မာစာတန်းကို လိုက်ပြပါသည်။ **English CC ကို ဆက်ဖွင့်ထားရန် လိုပါသည်။** စာတန်းရှာမည်နှိပ်ချိန်တွင် လိုအပ်လျှင် Transcript ကို 4 စက္ကန့်အထိ ခဏဖွင့်ဖတ်ပြီး ယခင် sidebar tab ကို ပြန်ထား သို့မဟုတ် sidebar ပိတ်ပေးပါသည်။ မူလက Transcript ဖွင့်ထားပြီးသားဆို မပိတ်ပါ။

CC မရှိသည့်ကွက်လပ်၊ Off လုပ်ချိန်နှင့် အခြားဘာသာစကားရွေးချိန်တွင် Transcript မှဆင်းသက်လာသော overlay ကို မပြပါ။ စာကြောင်းတူ ထပ်ပါလျှင် လက်ရှိနေရာနှင့် အနီးဆုံးစာကြောင်းကို သုံးသောကြောင့် အကြောင်းအရာအလိုက် ဘာသာပြန်ပုံ ကွဲနိုင်ပါသည်။ Udemy ပြောင်းလဲလျှင် adapter ပြင်ရန် လိုနိုင်ပါသည်။

ပုံမှန် video နှင့် HTML player container fullscreen ကို ထောက်ပံ့ပါသည်။ Browser က video element ကိုသာ fullscreen ပြသလျှင် HTML overlay မပြနိုင်ပါ။ ထိုအခါ fullscreen ထွက်ပြီး theater mode သုံးပါ။ Picture-in-Picture မှာ overlay မပေါ်ပါ။ **မြန်မာစာတန်း ပြမည်** ကို ပိတ်လျှင် မူလ English CC ကို မြင်ကွင်းမှာ ပြန်ပြပါသည်။ ဘာသာပြန်ပြီးသည်အထိ မြန်မာစာတန်း မပေါ်သေးနိုင်ပါ။

Key ကို sync မလုပ်ဘဲ ဒီ Chrome profile ထဲမှာသာ သိမ်းပါသည်။ Content script က key ကို storage မှ တိုက်ရိုက်ဖတ်မရအောင် trusted contexts သာ ခွင့်ပြုထားပါသည်။ သို့သော် local storage သည် encrypted vault မဟုတ်ပါ။ ကိုယ့် key ကို extension source ထဲ မရေးထည့်ပါနှင့်။

Subtitle စာသားကို Gemini သို့ပို့ပြီး ဘာသာပြန်ပါသည်။ Udemy password၊ cookies၊ video နှင့် အသံကို မပို့ပါ။ ဘာသာပြန်မှားနိုင်သောကြောင့် မူလ English နှင့် တွဲစစ်ပါ။ သင့် account ဖြင့် ဝင်ကြည့်နိုင်သော သင်ခန်းစာအတွက် ကိုယ်တိုင်သုံးရန် ဖြစ်ပါသည်။

Default model သည် `gemini-3.5-flash-lite` ဖြစ်ပြီး popup မှ ပြောင်းနိုင်ပါသည်။ Model မရတော့လျှင် သင့် Google AI Studio account တွင် ရနိုင်သော structured-output model အမည် ထည့်ပါ။ HTTP 429 ဖြစ်လျှင် quota/billing စစ်ပြီး ခဏစောင့်ပါ။ API error စာသားကို key ပါလာနိုင်သဖြင့် တိုက်ရိုက်မပြပါ။
